        About AC-SLAM
        
      

      

        

          
          

            
AC-SLAM Mission Control

            
v1.0 · 2026

          

        

        

        
Multi-Agent Mobile Robot System for Active Collaborative SLAM Application

        

          This platform was developed as part of an Engineering Thesis by
          Ferroukhi Khaled and Meddas Aymen,
          presented in 2026 at the École Nationale Polytechnique (ENP), Algiers.
        

        

          The system enables real-time teleoperation and coordinated exploration of multiple autonomous mobile robots
          performing simultaneous localization and mapping (SLAM). It provides an integrated mission control interface
          for map visualization, graph-based environment partitioning, and multi-robot task deployment.
